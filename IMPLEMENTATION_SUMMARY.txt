LOGIN FLOW:
  User → /login
    ↓
  Enters credentials
    ↓
  Checked against mockUsers
    ↓
  If Admin → Stored in sessionStorage
    ↓
  Redirect to /admin
    ↓
  Admin dashboard loads

ADMIN OPERATIONS FLOW:
  Admin → /admin loads
    ↓
  Check sessionStorage for user
    ↓
  Verify role === "Admin"
    ↓
  Load PricingManagement + BankSettingsForm
    ↓
  User modifies settings (mock updates)
    ↓
  Toast notification confirms change
