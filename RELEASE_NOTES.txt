INSTALLATION & DEPLOYMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PREREQUISITES
  • Node.js 18+
  • npm or pnpm
  • Modern browser

INSTALLATION
  1. Clone repository
  2. Run: pnpm install
  3. Run: pnpm dev
  4. Visit: http://localhost:3000

DEPLOYMENT
  1. Review DEPLOYMENT_CHECKLIST.txt
  2. Run tests and audits
  3. Get all approvals
  4. Deploy to Vercel (recommended)
  5. Monitor post-deployment
