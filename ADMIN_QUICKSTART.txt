💰 TARIFICATION - 3 MODÈLES
================================================================================

FIXE:
   └─ Montant fixe par période
   └─ Exemple: 100 MAD/mois
   └─ Champs: Amount, Devise, Cycle

VARIABLE:
   └─ Basé sur taux (%)
   └─ Exemple: 0.5% du montant transféré
   └─ Champs: Taux, Critères, Min/Max Frais

HYBRIDE:
   └─ Fixe + Variable
   └─ Exemple: 500 MAD/mois + 0.25%
   └─ Champs: Partie Fixe (Tabs) + Variable

COMMENT UTILISER:
1. Cliquer sur type (Fixe/Variable/Hybride)
2. Remplir les champs (auto-highlight)
3. Voir le résumé en temps réel
4. Cliquer "Enregistrer la Configuration"
5. Message de succès ✓

🐛 PROBLÈMES COMMUNS
================================================================================

PROBLÈME: Pas d'accès à /admin
SOLUTION:
   • Vérifier rôle = "Admin"
   • Vérifier sessionStorage
   • Recharger la page (F5)
   • Vérifier console (F12)

PROBLÈME: Champs ne changent pas au toggle
SOLUTION:
   • Cliquer sur le bon type
   • Attendre 100ms
   • Recharger la page
   • Vérifier console

PROBLÈME: Messages ne s'affichent pas
SOLUTION:
   • Vérifier l'alert est visible
   • Attendre 3 secondes (auto-close)
   • Ouvrir console pour erreurs
   • Tester sur navigateur différent

PROBLÈME: Moteur Externe ne teste pas
SOLUTION:
   • Vérifier URL valide (https://)
   • Vérifier Clé API correcte
   • Tester endpoint manuellement
   • Consulter documentation API

❓ QUESTIONS FRÉQUENTES
================================================================================

Q: Comment changer le type de tarification?
A: Cliquer sur le nouveau type (fixe/variable/hybride), 
   les champs changent automatiquement.

Q: Où stocker les configurations?
A: Actuellement en local state. Pour persistance:
   Implémenter API backend + database.

Q: Comment tester moteur externe?
A: Fournir URL API valide (https://...), 
   clé API correcte, puis cliquer "Tester".

Q: Est-ce que Cash Pooling est caché?
A: OUI. Aucune trace du CP dans Admin.
   Admin ne voit QUE tarification + paramètres.

Q: Peut-on exporter la configuration?
A: Pas encore. Future feature: export PDF/JSON.

Q: Comment ajouter utilisateurs?
A: Actuellement pas de gestion utilisateurs dans Admin.
   Peut être implémenté en phase 2.

Q: Support du dark mode?
A: Non actuellement. Interface en white theme uniquement.
   Dark mode peut être ajouté facilement (phase 2).
